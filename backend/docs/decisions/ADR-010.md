# ADR-010: LLM Provider Abstraction

## Context
Portfolio reviewers and interviewers will ask 'what if you had to switch providers' -- the answer needs to be an architectural fact, not a promise.

## Decision
Define LLMProvider (app/providers/base.py) with generate_structured(); ship MockProvider (default, zero-cost, deterministic), OpenAIProvider, GroqProvider (subclasses OpenAIProvider's OpenAI-compatible wire format), and a GeminiProvider stub. Selection is one env var (LLM_PROVIDER), read once in providers/factory.py.

## Alternatives Considered
- Hard-code one provider's SDK throughout the AI Service: rejected explicitly by the spec (section 9) -- would require touching every call site to add a provider.

## Consequences
Adding a genuinely new, non-OpenAI-compatible provider (e.g. finishing the Gemini stub) is scoped to one new file implementing one method; the LangGraph flow, tools, and routes never change.
